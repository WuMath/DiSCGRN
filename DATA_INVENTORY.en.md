# Manuscript input inventory

All paths below are **relative to this repository**. Copy the corresponding files into `Data/` while preserving subdirectories. `python scripts/check_paper_inputs.py` checks the required external inputs. Generated `Data/processed/` and `results/` are not downloaded source data.

| Use | Destination in this project | Upstream download |
|---|---|---|
| DREAM4 base topology | `Data/raw/dream4/DREAM4 in-silico challenge/Size 10/Supplementary information/insilico_size10_1/Goldstandard/insilico_size10_1_goldstandard_signed.tsv` | [GeneNetWeaver DREAM4 archive](https://gnw.sourceforge.net/resources/DREAM4%20in%20silico%20challenge.zip), [description](https://gnw.sourceforge.net/dreamchallenge.html) |
| Thirty BEELINE runs | `Data/raw/beeline/Synthetic/dyn-LI/dyn-LI-{100,200,500}-{1..10}/`, each with `ExpressionData.csv`, `PseudoTime.csv`, `GroundTruth.csv`, and `refNetwork.csv` | [`beeline_datasets.zip`, Zenodo 7682713](https://zenodo.org/records/7682713); archive MD5 `857cb335da79d09865cd7db2549fbda4` |
| Mouse lung expression | `Data/raw/gse74243/GSE74243_matrix_RMAlog2expressionvalues.txt.gz` | [GEO supplement](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE74nnn/GSE74243/suppl/GSE74243_matrix_RMAlog2expressionvalues.txt.gz) |
| GSE74243 sample and probe audit | `Data/raw/gse74243/GSE74243_series_matrix.txt.gz`, `GSE74243_Probes_BultLung2015.tsv.gz` | [GEO series matrix](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE74nnn/GSE74243/matrix/GSE74243_series_matrix.txt.gz), [probe table](https://ftp.ncbi.nlm.nih.gov/geo/series/GSE74nnn/GSE74243/suppl/GSE74243_Probes_BultLung2015.tsv.gz) |
| Candidate regulators | `Data/external/collectri_mouse.tsv` | [OmniPath mouse CollecTRI API](https://omnipathdb.org/interactions?datasets=tf_target&resources=CollecTRI&organisms=10090&format=tsv&fields=sources,references&genesymbols=1) |
| Mouse GO and ontology | `Data/external/mouse_pathway_annotations_20261007/MOUSE-mod.gaf.gz`, `go-basic.obo` | [mouse GAF](https://current.geneontology.org/annotations/gaf/MOUSE-mod.gaf.gz), [GO ontology](https://current.geneontology.org/ontology/go-basic.obo) |
| MGI mapping | `Data/external/mouse_pathway_annotations_20261007/MGI_Gene_Model_Coord.rpt` | [MGI report](https://www.informatics.jax.org/downloads/reports/MGI_Gene_Model_Coord.rpt) |
| Mouse KEGG pathways and links | `Data/external/mouse_pathway_annotations_20261007/kegg_mouse_pathways.tsv`, `kegg_mouse_pathway_genes.tsv` | [pathways](https://rest.kegg.jp/list/pathway/mmu), [pathway–gene links](https://rest.kegg.jp/link/mmu/pathway) |
| Annotation provenance | `Data/external/mouse_pathway_annotations_20261007/manifest.json` | Generated by `scripts/download_mouse_pathway_annotations.py` with checksums |

For extended historical analyses, the entire `Data/raw/dream4/` tree may also be copied. Its other four 10-gene topologies and native expression time series are not the expression input to the main simulated trajectories. `Data/processed/three_stage_global_500_30tf_allpairs_20261008/` is a generated 515-gene panel and can be rebuilt from GSE74243 and CollecTRI.

To **regenerate paper figures without rerunning expensive fits**, also copy these generated caches from the old project into identically named relative paths under `results/`: `revision_e3/`, `runs/weighted_score_20261004/`, `beeline_extended_valid_20261009/`, `runs/grn_accuracy_20261009/`, `real_p0_all_tf_targets_20261008/`, `real_p0_all_tf_targets_stage_case_20261008/`, `real_p0_all_tf_targets_all_regulators_20261008/`, and `real_p0_all_tf_targets_pathways_20261008/`. These are reproducible **outputs**, not external raw datasets. Some scripts refuse to overwrite existing outputs, so leave `results/` empty for a clean rerun.
